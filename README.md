# Kitbash

Kitbash is a desktop app for the people who make a game's content.

A game is full of things somebody has to sit down and write out. Items, levels,
characters, the numbers behind all of it. Kitbash is where that work happens, in
a window built for it, so the game engine does not have to be open at all.

It runs on Windows, on Linux and on macOS.

## Where it is

Early. The launcher works and updates itself, and the look and the pieces it is
built from are done. The tools it will hold are still being made.
